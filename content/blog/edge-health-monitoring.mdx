## Overview

This project focuses on building a real-time cardiovascular health monitoring system using IoT devices, edge computing, and machine learning techniques.

The system was designed to support continuous health monitoring and early detection of heart-related risks using demographic, physiological, and lifestyle factors.

## System Architecture

The architecture integrates:
- IoT-enabled health data collection
- Edge computing for low-latency processing
- Machine learning-based heart disease prediction
- Cloud deployment using Docker and Kubernetes

An iOS-based frontend was developed for real-time monitoring and interaction with connected devices.

## Edge Computing Integration

Edge processing was used to:
- Reduce inference latency
- Improve reliability during unstable connectivity
- Enable near real-time health monitoring
- Minimize unnecessary cloud communication

This approach improved responsiveness and scalability for healthcare monitoring workflows.

## Machine Learning Pipeline

The predictive pipeline used:
- Demographic features
- Lifestyle indicators
- Physiological measurements
- Feature engineering techniques
- Standardized preprocessing workflows

Multiple machine learning models were evaluated including:
- Random Forest
- Logistic Regression
- XGBoost
- LightGBM

## Results

The final optimized models achieved:
- ROC-AUC around 0.80
- Strong precision-recall balance
- Improved predictive reliability for cardiovascular risk assessment

Feature importance analysis identified:
- Pulse pressure
- Cholesterol
- Stress
- Lifestyle indicators
as major predictors.
