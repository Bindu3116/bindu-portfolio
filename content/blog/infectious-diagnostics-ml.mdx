## Overview

This project presents a supervised machine learning framework for infectious disease prediction using the Mexico National Epidemiological Surveillance Dataset.

The system was designed to support scalable healthcare diagnostics in resource-limited environments.

## Dataset

- 263,000+ epidemiological records
- Demographic data
- Comorbidity indicators
- Clinical symptom timelines
- Public health surveillance variables

## Methodology

The pipeline includes:
- Missing-value correction
- Feature engineering
- Class imbalance handling
- One-hot encoding
- Standardization
- XGBoost optimization

## Engineered Features

- Comorbidity count
- Symptom-to-admission interval
- Age-group categorization
- Temporal epidemiological features

## Results

- ROC-AUC: 0.80
- Recall: 0.73
- Macro F1-score: 0.72

The tuned XGBoost classifier outperformed baseline ensemble models across clinically relevant evaluation metrics.
