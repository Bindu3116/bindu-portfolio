## Overview

NeuroFusionGPT is a multimodal deep learning framework developed for physiological stress classification using EEG and ECG biosignals.

The system combines:
- Transformer-based EEG encoding
- MLP-based ECG encoding
- Bidirectional cross-attention fusion
- LLM-generated wellness feedback

## Architecture

The EEG encoder treats 16 EEG channels as sequential tokens and processes them using a Transformer encoder with positional encoding.

The ECG encoder processes 187-dimensional ECG feature vectors through a multi-layer perceptron with batch normalization.

Both embeddings are fused using bidirectional cross-attention to model brain-heart coupling patterns.

## Results

- Test Accuracy: 94.54%
- Balanced Accuracy: 91.93%
- Macro F1-score: 0.8052
- Total Parameters: 679,557

The model achieved strong performance on Calm and Severe Stress classes while maintaining robust minority-class recall through focal loss and class weighting.
